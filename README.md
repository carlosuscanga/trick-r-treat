# Trick-r-Treat

Juego web móvil de Halloween hecho con Phaser 3, TypeScript y Vite. Una niña con disfraz recorre la calle tocando puertas: cada vecino le pone un minijuego para darle su dulce, y si falla, le da un susto.

## Documentación

- [Diseño del juego](docs/diseno/README.md): concepto, reglas y personajes.
- [Tareas](docs/tareas/README.md): tablero con el avance.
- [Planes](docs/planes/README.md): planes de implementación.

## Desarrollo

- `npm install`: instala dependencias.
- `npm run dev -- --host`: servidor de desarrollo.
- `npm run build`: revisa tipos y genera `dist/`.

Las versiones exactas de las dependencias están en `package.json`.
