## Qué

## Por qué

Safari en iOS es el mayor riesgo técnico (rendimiento, audio y pantalla completa). Mejor descubrirlo pronto.

## Criterios de aceptación

- [ ] Abre y se juega desde Safari usando el link de GitHub Pages.
- [ ] Funciona añadido a la pantalla de inicio (pantalla completa).
- [ ] Los controles táctiles responden bien.
- [ ] Un sonido de prueba suena después del primer toque.
- [ ] Problemas encontrados registrados como tareas nuevas.
