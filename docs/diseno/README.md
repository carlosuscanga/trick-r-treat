# Diseño del juego

Qué es el juego y cómo se juega, explicado para cualquier persona. Aquí no va código ni detalles técnicos (eso vive en `CLAUDE.md`).

**Versión del diseño: v0.2** (2026-10-16). Historial en [CAMBIOS.md](CAMBIOS.md).

## Propósito

- Es un regalo para **Mi vo**, que además es la protagonista.
- Es un proyecto para aprender el ciclo completo de desarrollo de un videojuego desde todos los roles: product owner, manager y desarrollador. Los agentes de IA escriben el código; nosotros lo dirigimos y lo revisamos.
- La v1 no tiene fecha: se entrega cuando esté lista.
- **Jugadora:** Mi vo juega de forma casual. Puede haber reto, pero las reglas deben entenderse rápido y perder no debe frustrar.
